# 技能多等级系统重构计划

## 📋 项目背景

当前技能升级系统使用独立SO方案存在技能效果叠加问题。玩家选择1级技能后再选2级技能，两个效果会同时生效，不符合技能升级的游戏逻辑。

## 🎯 新方案概述

采用**一个SO包含多个等级**的方案，每个技能的所有等级在同一个配置中管理，同一时间只有一个等级生效，实现真正的技能升级替换机制。

## 🔧 技术方案

### 1. 技能配置结构重构

#### 1.1 新的SkillConfig结构
- 保留现有的技能基本信息（名称、描述、标签）
- 添加技能等级列表（`skillLevels`）
- 保留解锁条件配置
- 移除单独的`isActive`字段（由等级控制）

#### 1.2 技能等级配置
每个等级包含：
- 等级编号（1、2、3...）
- 是否激活（控制该等级是否可用）
- 等级描述（该等级的特殊说明）
- 完整的技能组件配置（触发器、条件、效果、重置条件等）

### 2. 技能升级逻辑

#### 2.1 等级激活机制
- 玩家首次选择技能时，激活等级1
- 再次选择同一技能时，升级到下一等级
- 同一时间只有一个等级生效
- 高级等级会替换低级等级的效果

#### 2.2 技能选择流程
1. 玩家完成关卡
2. 系统生成技能选择（包含已拥有技能的升级选项）
3. 玩家选择技能
4. 如果是新技能：激活等级1
5. 如果是已有技能：升级到下一等级

### 3. 与现有系统的集成

#### 3.1 保持现有组件
- 触发器配置（TriggerConfig）
- 条件配置（ConditionConfig）
- 效果配置（SkillEffectConfig）
- 重置条件配置（ResetConditionConfig）
- 效果移除配置（EffectRemovalConfig）

#### 3.2 修改现有管理器
- `SkillManager`：管理技能等级状态
- `SkillSelectionManager`：处理技能升级逻辑
- `SkillInstance`：根据当前等级创建实例

## 🎮 游戏体验

### 技能选择界面
- 新技能显示为"碰撞连击"
- 已拥有技能显示为"碰撞连击 Lv2"（可升级）
- 已满级技能不显示在选择列表中

### 技能升级流程
1. 玩家拥有"碰撞连击 Lv1"
2. 关卡完成后，技能选择显示"碰撞连击 Lv2"
3. 玩家选择后，Lv1效果被替换为Lv2效果
4. 下次选择时显示"碰撞连击 Lv3"

## 📈 优势分析

### 相比当前方案的优势
1. **符合游戏逻辑**：技能升级是替换，不是叠加
2. **用户体验好**：玩家明确知道这是技能升级
3. **配置简单**：所有等级在一个地方管理
4. **避免错误**：不会出现效果叠加的问题
5. **扩展性强**：可以轻松添加更多等级

### 保持现有架构的优势
1. **复用现有组件**：所有触发器、条件、效果组件都可以保留
2. **渐进式升级**：可以逐步迁移现有技能
3. **风险较低**：核心逻辑变化不大
4. **维护性强**：技能配置更加集中和清晰

## 🚀 实施建议

### 优先级排序
1. **高优先级**：数据结构重构和等级管理
2. **中优先级**：技能选择逻辑修改
3. **低优先级**：UI优化和高级功能

### 风险控制
1. **渐进式实施**：先重构数据结构，再修改逻辑
2. **向后兼容**：保持现有API的基本兼容性
3. **充分测试**：每个阶段都要进行充分测试

### 成功标准
1. 技能升级逻辑正确可靠
2. 不会出现效果叠加问题
3. 技能配置简单直观
4. 玩家体验流畅自然

## 📝 总结

这个多等级方案完美解决了技能效果叠加的问题，通过一个SO管理多个等级，实现了真正的技能升级替换机制。方案简单、实用、风险低，能够提供更好的游戏体验。
