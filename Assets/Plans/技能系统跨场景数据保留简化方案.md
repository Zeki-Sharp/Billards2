## 🎯 方案概述

基于代码分析，确认以下简化方案完全可行：

### 核心思路
1. **创建静态数据类**：管理4个临时属性（当前血量、最大血量、伤害值、攻击范围）
2. **移除 PlayerStateManager**：其功能被静态类完全替代
3. **保持 SkillManager 跨场景**：技能列表自动保留，只需重新初始化技能实例
4. **修改属性获取逻辑**：各系统从静态类读取最终值

### 步骤1：创建 GameRuntimeData 静态类 (0.5天)

**文件**：`Assets/Scripts/Core/GameRuntimeData.cs`

```csharp
public static class GameRuntimeData
{
    // 4个临时属性
    private static float currentHealth = -1f;
    private static float maxHealth = -1f;
    private static float damage = -1f;
    private static float attackRange = -1f;
    
    // 初始化
    public static void Initialize()
    {
        currentHealth = -1f;
        maxHealth = -1f;
        damage = -1f;
        attackRange = -1f;
    }
    
    // 当前血量
    public static void SetCurrentHealth(float health) => currentHealth = health;
    public static float GetCurrentHealth() => currentHealth;
    public static bool HasCurrentHealthData() => currentHealth >= 0f;
    
    // 最大血量
    public static void SetMaxHealth(float health) => maxHealth = health;
    public static float GetMaxHealth() => maxHealth;
    public static bool HasMaxHealthData() => maxHealth >= 0f;
    
    // 伤害值
    public static void SetDamage(float damageValue) => damage = damageValue;
    public static float GetDamage() => damage;
    public static bool HasDamageData() => damage >= 0f;
    
    // 攻击范围
    public static void SetAttackRange(float range) => attackRange = range;
    public static float GetAttackRange() => attackRange;
    public static bool HasAttackRangeData() => attackRange >= 0f;
    
    // 清理数据
    public static void ClearAllData()
    {
        currentHealth = -1f;
        maxHealth = -1f;
        damage = -1f;
        attackRange = -1f;
    }
}
```

**验证标准**：
- 静态类可以正常创建和访问
- 数据在场景切换后保留

### 步骤2：修改 PlayerStatsManager (1天)

**修改 `GetFinalStat()` 方法**：
```csharp
public float GetFinalStat(string statName)
{
    // ✅ 优先从静态数据读取最终值
    switch (statName)
    {
        case "MaxHealth":
            if (GameRuntimeData.HasMaxHealthData())
                return GameRuntimeData.GetMaxHealth();
            break;
        case "Damage":
            if (GameRuntimeData.HasDamageData())
                return GameRuntimeData.GetDamage();
            break;
        case "AreaRadius":
            if (GameRuntimeData.HasAttackRangeData())
                return GameRuntimeData.GetAttackRange();
            break;
    }
    
    // 如果没有保存的最终值，则重新计算
    return CalculateFinalStat(statName);
}
```

**修改 `OnStatChanged()` 方法**：
```csharp
private void OnStatChanged(string statName)
{
    // 计算最终值
    float finalValue = CalculateFinalStat(statName);
    
    // ✅ 保存到静态数据
    switch (statName)
    {
        case "MaxHealth":
            GameRuntimeData.SetMaxHealth(finalValue);
            break;
        case "Damage":
            GameRuntimeData.SetDamage(finalValue);
            break;
        case "AreaRadius":
            GameRuntimeData.SetAttackRange(finalValue);
            break;
    }
    
    cacheDirty = true;
}
```

**验证标准**：
- 属性变化时正确保存到静态类

### 步骤4：修改 SkillManager (0.5天)

**添加重新初始化方法**：
```csharp
void Start()
{
    // 查找技能状态管理器
    skillStateManager = FindFirstObjectByType<SkillStateManager>();
    
    // ✅ 重新初始化技能实例（保持技能配置，重建实例）
    ReinitializeSkillInstances();
    
    SubscribeToEvents();
}

void ReinitializeSkillInstances()
{
    // 清除旧的实例
    skillInstances.Clear();
    
    // 为每个技能重新创建实例
    foreach (var skillConfig in activeSkills)
    {
        if (skillConfig != null && skillConfig.IsValid())
        {
            var skillInstance = skillConfig.CreateSkillInstance();
            if (skillInstance != null)
            {
                skillInstances[skillConfig.skillName] = skillInstance;
                
                // 通知技能状态管理器
                skillStateManager?.AddActiveSkill(skillConfig.skillName);
            }
        }
    }
    
    if (enableDebugLog)
    {
        Debug.Log($"SkillManager: 重新初始化完成，共加载 {skillInstances.Count} 个技能");
    }
}
```

**验证标准**：
- 新场景中技能实例正确重建

## 🎯 方案优势

### 1. 极简设计
- 只需要1个新文件（GameRuntimeData）
- 修改4个现有文件
- 删除1个文件（PlayerStateManager）

### 2. 职责清晰
```
GameRuntimeData: 静态数据仓库（4个属性）
PlayerStatsManager: 计算并保存最终值
PlayerCore: 使用最终血量值
SkillManager: 重新初始化技能实例
```

### 3. 数据流简单
```
Level1: 技能触发 → 修饰器应用 → 最终值计算 → 保存到 GameRuntimeData
        ↓
Level2: 从 GameRuntimeData 读取最终值 → 技能重新触发 → 修饰器重新创建
        ↓
        所有系统正常工作 ✅
```

### 4. 易于维护
- 不需要复杂的序列化
- 不需要管理修饰器生命周期
- 调试简单，数据清晰
