# 跨关卡数据保留功能实现计划

## 项目概述

实现玩家数据在关卡间的无缝保留，确保游戏体验的连续性。主要解决血量、技能效果和属性修饰器的跨关卡传递问题。

## 需求分析

### 核心需求
1. **血量保留**：玩家在关卡结束时的血量状态需要在新关卡开始时恢复
2. **修饰器保留**：所有未移除的属性修饰器需要在关卡间保留
3. **技能继承**：已获得的技能配置跨关卡保留（SkillManager已实现）

### 技术约束
- SkillManager使用单例模式，已实现跨场景保留
- 技能不会重复触发，避免修饰器重复应用
- 修饰器有生命周期管理，只保留未移除的修饰器

## 架构设计

### 核心组件
1. **PlayerStateManager**：跨关卡数据协调器
2. **PlayerCore**：血量管理，支持血量恢复
3. **PlayerStatsManager**：修饰器管理，支持序列化和恢复
4. **LevelManager**：关卡流程管理，集成保存/恢复调用

### 数据流向
```
关卡完成 → 保存玩家状态 → 场景切换 → 新关卡开始 → 恢复玩家状态
```
