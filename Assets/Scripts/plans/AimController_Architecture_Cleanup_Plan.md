# AimController 架构清理计划

## 文档信息
- **创建日期**: 2024年12月
- **版本**: 1.0
- **状态**: 计划阶段
- **优先级**: 高
- **最后更新**: 2024年12月

## 概述

本文档分析了 `AimController.cs` 中存在的重复架构问题，并提供了分阶段的清理方案。通过逐步清理重复实现，将 `AimController` 从"全能控制器"简化为"协调器"，充分利用现有的组件架构。

## 问题分析

### 当前状况
- **代码行数**: 848行
- **主要问题**: 承担过多职责，重复实现现有功能
- **架构问题**: 与现有组件功能重复

### 重复架构识别

#### 1. 输入处理重复
- **重复组件**: `PlayerInputHandler`
- **重复功能**: 鼠标输入处理、坐标转换
- **影响代码**: `UpdateAimDirection()`, `GetMouseWorldPosition()`

#### 2. UI管理重复
- **重复组件**: `ChargeBarUI`, `UIController`
- **重复功能**: UI状态管理、事件订阅
- **影响代码**: `ShowChargingUI()`, `HideChargingUI()`, `UpdateChargingProgress()`

#### 3. 渲染管理重复
- **重复组件**: `AimLineMaterialController`
- **重复功能**: LineRenderer管理、材质设置
- **影响代码**: `SetupAimLine()`, `CreateSegmentLine()`, `ClearSegmentLines()`

#### 4. 状态管理重复
- **重复组件**: `PlayerStateMachine`
- **重复功能**: 状态切换、状态管理
- **影响代码**: `isVisible` 状态管理

#### 5. 组件管理重复
- **重复组件**: `Player`, `GameManager`
- **重复功能**: 组件初始化、依赖管理
- **影响代码**: `InitializeController()`, `DelayedPlayerCoreSearch()`
