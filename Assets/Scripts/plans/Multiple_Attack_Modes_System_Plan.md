# 多种攻击方式系统实施计划

## 📋 项目概述

### **目标**
实现两种攻击方式系统（碰撞攻击、范围攻击），支持简单的角色选择界面，选择角色后玩家使用对应的攻击方式。

### **设计原则**
- **职责分离**：攻击系统与技能系统独立
- **配置驱动**：通过 ScriptableObject 配置攻击参数
- **接口统一**：所有攻击方式实现统一接口
- **易于扩展**：新增攻击方式只需实现接口

---

## 🏗️ 系统架构设计

### **分层架构**
```
角色选择层 → 配置数据层 → 行为实现层 → 执行层
     ↓           ↓           ↓          ↓
  选人界面  →  ScriptableObject → IPlayerAttackBehavior → PlayerCore
```

### **核心组件**
1. **AttackMode 枚举** - 定义两种攻击方式（碰撞、范围）
2. **AttackModeConfig** - 攻击方式配置数据
3. **IPlayerAttackBehavior** - 攻击行为接口
4. **AttackBehaviorFactory** - 攻击行为工厂
5. **ProfessionData** - 角色数据（包含攻击方式）
6. **CharacterSelectionUI** - 角色选择界面

## 🎯 技术要点

### **接口设计要点**
- 保持接口简洁，只包含必要方法
- 确保所有攻击方式都能实现接口
- 支持动态切换和重新初始化

### **配置系统要点**
- 使用 ScriptableObject 便于策划调整
- 支持运行时热更新
- 提供合理的默认值和验证

### **性能考虑**
- 避免在 Update 中频繁检查
- 合理使用对象池管理特效
- 优化碰撞检测和范围检测

### **扩展性考虑**
- 预留扩展接口和枚举
- 支持插件式攻击方式添加
- 保持向后兼容性
